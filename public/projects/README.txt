📸 Project Screenshots
======================
Place your project screenshot images here.

File naming:
  ems.png           → Employee Management System
  wanderlust.png    → WanderLust Travel Platform
  mcp-assistant.png → MCP AI Voice Assistant

Then in src/data.js, uncomment the `image` line for each project:
  image: "/projects/ems.png",

Recommended size: 1200×675px (16:9) or 1200×800px (3:2)
